# 🐍 Python Math Methods for Beginners

Welcome! Python has a built-in calculator toolkit called `math`. It helps you do advanced math operations easily without writing complex formulas yourself.

---

## 🔑 1. Getting Started

To use these math tools, you must first bring the math library into your code using the `import` command.

```python
# 🔓 Unlock the math tools
import math
```

---

## ⚙️ 2. Essential Math Functions

Here are the most common math methods you will use as a beginner:

* **`math.sqrt(x)`**: Finds the square root of a number.
* **`math.ceil(x)`**: Rounds a decimal number **up** to the nearest whole number.
* **`math.floor(x)`**: Rounds a decimal number **down** to the nearest whole number.

### 📝 Example Code:
```python
import math

# 🔢 Square Root
print(math.sqrt(16))  # Output: 4.0

# ⬆️ Rounding Up
print(math.ceil(4.2))  # Output: 5

# ⬇️ Rounding Down
print(math.floor(4.8))  # Output: 4
```

---

## 📊 3. Built-in comparison Functions

These helpful functions are built directly into Python. You do **not** need to type `math.` before using them!

* **`abs(x)`**: Finds the absolute (positive) distance of a number from zero. It turns negative numbers into positive numbers.
* **`min(x, y, z...)`**: Looks at a list of numbers and picks the **smallest** one.
* **`max(x, y, z...)`**: Looks at a list of numbers and picks the **largest** one.

### 📝 Example Code:
```python
# ➕ Absolute Value
print(abs(-7))         # Output: 7
print(abs(5))          # Output: 5

# 📉 Finding the Minimum
print(min(5, 12, 3, 8))  # Output: 3

# 📈 Finding the Maximum
print(max(5, 12, 3, 8))  # Output: 12
```

---

## 📐 4. Important Math Constants

The `math` tool also stores famous mathematical constants so you do not have to memorize their long decimal numbers:

* **`math.pi`**: The value of Pi (π ≈ 3.14159).
* **`math.e`**: Euler's number (e ≈ 2.71828).

### 📝 Example Code:
```python
import math

# 🥧 Using Pi
print(math.pi)  # Output: 3.141592653589793
```
